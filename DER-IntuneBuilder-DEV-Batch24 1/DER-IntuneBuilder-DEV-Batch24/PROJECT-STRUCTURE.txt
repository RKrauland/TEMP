DER Intune / Entra Environment Builder v1 - Source Tree
=======================================================

This file describes the current package layout and responsibility boundaries.
Build numbers identify sealed package bytes; the product remains v1 until the
project owner explicitly authorizes a version change.

Runtime state is never stored beside the package. DER selects a writable local
fixed-volume root, preferring C:\ProgramData\DER\IntuneBuilder and falling back
to LOCALAPPDATA only when that fallback is also on a local fixed volume.

Per-run evidence begins with DER-LogIndex.json and includes human, technical,
engine timeline, action timeline, combined error, ENGINE error, ACTION error,
Graph, validation, rollback, and PowerShell transcript streams. See Docs\LOGGING-REFERENCE.md for triage rules.
